# Flight Delay Time Statistics Dashboard

Este proyecto es un tablero interactivo (*dashboard*) desarrollado en Python utilizando **Dash** y **Plotly** para analizar las causas y tiempos de retraso en vuelos comerciales por aerolínea y año.

## 🚀 Estructura del Proyecto

* `flight_delay.py`: Script principal con la aplicación Dash y los callbacks interactivos.
* `4.8_Flight_Delay_Statistics_Dashboard.ipynb`: Cuaderno de Jupyter con las pruebas iniciales y análisis previo de datos.
* `airline_data.csv`: Conjunto de datos con la información de los vuelos.
* `requirements.txt`: Lista de dependencias del proyecto.
* `Procfile`: Configuración para el despliegue del servidor con Gunicorn.
